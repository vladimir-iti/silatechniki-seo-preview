# Предпросмотр статей силатехники.рф

Отдельный статический хаб для просмотра всех 50 статей сайта целиком.
Это не боевой сайт и не публикация на нём — только просмотр. Все страницы
закрыты от поисковиков (`robots: noindex, nofollow`): эти адреса на
силатехники.рф уже в выдаче, и дубль текстов на другом домене им навредил бы.

## Структура

- `scripts/` — исходный код сборки:
  - `build_site.mjs` — сборщик. Читает статьи сайта (`../src/content/articles/`)
    и переводит markdown в HTML тем же конвейером, что и Astro
    (`@astrojs/markdown-remark`). Ссылки на другие статьи становятся ссылками
    внутри хаба, остальные (посадочные страницы) — абсолютными ссылками на
    силатехники.рф. Картинки берутся из `../public/images/articles/`.
    Статьи разложены по тем же разделам, что на `/articles`.
  - `style.css` — типографика и вёрстка.
  - `check_site.py` — проверка собранного хаба: битые ссылки и картинки,
    наличие `noindex`, утечки файлов конвейера (`strategy.json`,
    `pipeline.json`), полнота набора статей. Отдельно предупреждает о
    служебных фразах генерации в тексте («в базе источников этой статьи нет»).
- `docs/` — собранный сайт (GitHub Pages читает именно эту папку).

## Пересборка

```bash
node preview/scripts/build_site.mjs      # из корня проекта silatechniki
python3 preview/scripts/check_site.py
```

Нужны Node 18+ (зависимости — из `node_modules` основного проекта) и Python 3.

## Локальный просмотр

```bash
cd preview/docs && python3 -m http.server 8123
```
